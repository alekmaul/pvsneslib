# Documentation and Wiki

PVSnesLib documentation is available in several complementary forms. Each has a different purpose; you do not need to choose only one.

## Official documentation

This MkDocs site is the structured starting point for learning and using PVSnesLib. It brings together:

- installation and first-project instructions;
- practical tutorials;
- guides to the SNES hardware and development tools;
- an overview of the examples;
- navigation to the generated API reference.

Use the navigation on this site to follow a learning path or find a topic.

## Generated API reference (Doxygen)

The [Doxygen API reference](https://alekmaul.github.io/pvsneslib/) is the place to look up documented functions, types and headers. It complements the conceptual explanations and tutorials on this site.

## Community Wiki

The [GitHub Wiki](https://github.com/alekmaul/pvsneslib/wiki) contains community-maintained material, practical notes and additional examples. It may cover subjects in more depth or include information that has not yet been integrated into the structured documentation.

The Wiki is complementary: it is not a replacement for the getting-started guides or the generated API reference.

## Keeping information consistent

The structured documentation, Doxygen reference and Wiki serve different needs and may not always be updated at the same time. When something appears unclear or inconsistent, check the project source and report the issue through the [GitHub repository](https://github.com/alekmaul/pvsneslib).
