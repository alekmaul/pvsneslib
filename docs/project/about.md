# About PVSnesLib

PVSnesLib is a development library for creating homebrew games and applications for the Super Nintendo Entertainment System (SNES).

The project brings together the library, development tools, examples and documentation needed to build software for the console. It is intended for developers who want to experiment with SNES hardware and create their own projects.

## Explore the project

- [Source code and releases](https://github.com/alekmaul/pvsneslib)
- [Community Wiki](https://github.com/alekmaul/pvsneslib/wiki)
- [Generated API reference](https://alekmaul.github.io/pvsneslib/)

## Start developing

If you are new to PVSnesLib, begin with the [Getting started](../getting-started/index.md) section. It explains where to begin, how to prepare the toolchain and how to build a first project.

Then continue with the [tutorials](../tutorials/index.md), browse the [examples](../examples/index.md), and consult the [API reference](../api/index.md) when you need details about library functions.
