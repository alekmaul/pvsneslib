# Frequently asked questions

This FAQ collects concise answers to recurring questions about PVSnesLib. Detailed procedures belong in the relevant installation, tutorial or API pages; community-specific tips can remain in the [GitHub Wiki](https://github.com/alekmaul/pvsneslib/wiki).

## Where can I find installation instructions?

Start with [Installation](../getting-started/installation.md) for the release-based setup and the first build check. For the latest operating-system-specific details, also consult the [official Installation Wiki page](https://github.com/alekmaul/pvsneslib/wiki/Installation).

## How do I check that PVSnesLib is installed correctly?

Build the `snes-examples/hello_world` example by running `make` from its directory in a terminal configured for your operating system. The [Installation guide](../getting-started/installation.md) describes the verification step.

## Where can I find API details?

Use the [API reference](../api/index.md) for the structured overview and the [generated Doxygen documentation](https://alekmaul.github.io/pvsneslib/) for documented functions, types and headers.

## What is the GitHub Wiki for?

The Wiki remains a complementary community space for tips, troubleshooting, project notes and additional material. See [Documentation and Wiki](../project/documentation-and-wiki.md).

## Where should I report a problem?

Please use the [GitHub issue tracker](https://github.com/alekmaul/pvsneslib/issues). Include your operating system, toolchain version, PVSnesLib release or revision, and the smallest reproducible example you can provide.
