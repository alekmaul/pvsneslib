## Suggested learning path

1. Start with [Getting started](../getting-started/index.md) and build the first project.
2. Follow [Graphics and backgrounds](graphics.md) to prepare visual assets.
3. Learn [Sprites](sprites.md) to display and move objects on screen.
4. Add [Controller input](input.md) to make the project interactive.
5. Explore [Audio](audio.md) to add music and sound effects.

## Need more detail?

- Consult the [API reference](../api/index.md) for function and header documentation.
- Browse the [SNES hardware overview](../hardware/index.md) to understand the console's main video, audio and memory components.
- Visit the [Community Wiki](https://github.com/alekmaul/pvsneslib/wiki) for supplementary notes and community-maintained material.

The tutorials are intended as practical entry points. For exact function signatures and low-level details, use the API reference alongside the relevant guide.
