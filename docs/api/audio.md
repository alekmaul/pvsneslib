# Audio API

The audio API documents the PVSnesLib interface to the SNES sound subsystem, including the sound driver, music playback, and sound effects.

**Open:** [PVSnesLib generated API reference](https://alekmaul.github.io/pvsneslib/)

**Source headers:** [PVSnesLib SNES headers](https://github.com/alekmaul/pvsneslib/tree/master/pvsneslib/include/snes)

## Look up

- Starting and communicating with the audio system.
- Loading music data and sound banks.
- Starting and stopping music playback.
- Loading and triggering sound effects.
- Audio processing calls that must be integrated into the main loop.

Use the declarations and Doxygen descriptions for exact function names, arguments, and constraints. Audio resource conversion is covered separately in the [Development tools](../tools/index.md) page.
