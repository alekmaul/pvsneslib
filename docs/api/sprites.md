# Sprites API

The sprite API provides helpers for managing SNES hardware objects through OAM. Use the generated reference for exact function signatures, parameter meanings, constants, and supported sprite attributes.

**Open:** [PVSnesLib generated API reference](https://alekmaul.github.io/pvsneslib/)

**Source headers:** [PVSnesLib SNES headers](https://github.com/alekmaul/pvsneslib/tree/master/pvsneslib/include/snes)

## Look up

- OAM initialization and sprite attribute setup.
- Sprite position and movement helpers.
- Tile and palette selection.
- Sprite size and priority.
- OAM updates and related hardware limits.

The API describes individual hardware sprites. Higher-level concepts such as dynamic sprites and metasprites combine those primitives into larger objects; see the related guide and examples.
